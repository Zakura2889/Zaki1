# Анализ предметной области

Автобаза оказывает услуги по перевозке пассажиров и грузов в черте города
и между соседними городами. Для регулярных рейсов оплата производится
в момент оказания услуги, в остальных случаях клиент оформляет заявку,
которая может быть отклонена.

Участники: диспетчер, водитель, клиент, бухгалтерия, налоговая инспекция.
Основные объекты: заявка, рейс, маршрут, автомобиль, водитель, путевой лист.
