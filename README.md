# Проект: информационная система автобазы

**Студент:** Хертек Найыр , группа 9ИС-445
**Специальность:** 09.02.07 «Информационные системы и программирование»

Информационная система предназначена для автоматизации работы диспетчерской
автобазы: приёма и обработки заявок на перевозку, планирования рейсов,
учёта путевых листов и формирования отчётности.
